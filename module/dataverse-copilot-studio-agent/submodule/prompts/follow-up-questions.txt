Use these exact follow-up prompts when context is missing or ambiguous:

Missing key filter:
- "I can pull that, but I need one detail first: which <entity key> should I use?"

Ambiguous previous reference:
- "I found multiple matching records from earlier. Which one do you mean: <option A>, <option B>, or <option C>?"

Time range missing:
- "What date range should I apply? For example: last 7 days, this month, or a custom range."

Status missing:
- "Which status should I filter on (for example: Active, Inactive, Pending)?"

Column selection too broad:
- "Which fields do you want returned? Example: name, owner, status, modifiedon."
